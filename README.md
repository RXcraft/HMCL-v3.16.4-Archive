# HMCL 3.16.4 纯净版存档 (非官方) #

##📌 建立此仓库的原因##
近期 HMCL 官方对部分国内下载渠道进行了限制.为了方便国内玩家获取**纯净,无捆绑,无后门**的官方原版启动器,特建立此 GitHub 存档仓库.

**⚠️ 郑重声明：本仓库为个人存档项目,并非 HMCL 官方仓库.** 

##📦 包含文件说明与选择指南##
所有文件均下载自 HMCL 官方 GitHub Releases.请根据你的操作系统选择下载：

###🖥️ Windows 用户推荐###
- **`HMCL-3.16.4.exe`**：安装包.适合电脑没有安装 Java 的新手,双击自动安装并配置环境.
- **`HMCL-3.16.4.zip`**：免安装便携版.解压即可使用,适合放在U盘或不想安装的用户.

###🍎 macOS / 🐧 Linux 用户推荐###
- **`HMCL-3.16.4.jar`**：**全平台通用版(强烈推荐)**.需要电脑已安装 Java 8 或更高版本,双击即可运行.
- **`HMCL-3.16.4.deb`**：适用于 Debian/Ubuntu 系统的安装包.
- **`HMCL-3.16.4.sh`**:Linux/macOS 通用安装脚本。
- **`HMCL-3.16.4.tar.gz`**：Linux 系统的压缩包.

###💻 开发者源码###
- **`源代码.zip / tar.gz`**：对应 3.16.4 版本的官方源码,供开发者审查或编译使用.

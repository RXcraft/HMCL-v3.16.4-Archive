#HMCL 3.16.4 纯净版存档 (非官方)

##📌 建立此仓库的原因
近期 HMCL 官方对部分国内下载渠道进行了限制.为了方便国内玩家获取**纯净,无捆绑,无后门**的官方原版启动器,特建立此 GitHub 存档仓库.

**⚠️ 郑重声明：本仓库为个人存档项目,并非 HMCL 官方仓库.** 

##📦 包含内容
- `HMCL-3.16.4.exe`(Windows 安装包)
- `HMCL-3.16.4.jar`(跨平台通用版本)
- `源代码.zip`(对应版本的官方源码)
*(注：请根据你实际下载的文件修改上方列表)*

##🛡️ 安全保证与开源协议
一本仓库所有文件均下载自 HMCL 官方 GitHub Releases.
2. HMCL 采用 **GPL-3.0 开源协议**,本仓库严格遵守该协议,同时提供编译后的安装包与对应源码.
二[HMCL-dev/HMCL](https://github.com/HMCL-dev/HMCL).

##🚀 如何下载
一点击本页面右侧的**发布版本**标签页,或直接在代码根目录点击对应文件下载.
二如果 GitHub 访问缓慢,建议使用 Watt Toolkit (Steam++ 等开源加速工具) 或开启代理进行下载.
